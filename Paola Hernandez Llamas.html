Reconstructing quarter-hour electricity prices 1st place overall and AET category winner at Neural Wave Hackathon 2026, Lugano.

Given only a day's 24 hourly electricity prices in four market zones, our team rebuilt its 96 quarter-hour prices while keeping every hourly average exact. On held-out September days the error was 54% lower than repeating the hourly price.

What we did

  • Started from a smooth interpolation that keeps each hourly average, then trained three LightGBM models for slope, curvature and zigzag corrections inside each hour.
  • Kept it explainable: every prediction is a baseline plus three named, zero-sum shape corrections.
  • Picked the model on eight monthly validation folds, added a risk flag for hard hours (2.8–3.9× higher error), and built a Streamlit dashboard.

Possible improvements

  • Turn the risk flag into calibrated prediction intervals, so each hour comes with an honest uncertainty range.
  • Add what drives quarter-hour swings, such as solar and wind forecasts and demand, which the official data didn't include.
  • Test on a month nobody has looked at, since September was scored twice during model selection.

From one prompt to a compound AI system Small, focused prompts checked by Python beat one engineered prompt on a board-game recommender.

The task: given a request and five board games, pick the one game that meets every requirement, or decline if none does. We compared one carefully engineered prompt with a compound system of focused prompts whose answers plain Python verifies.

What we did

  • Designed each prompt for one narrow job with a structured output schema, retrying once if a reply doesn't fit.
  • Made the model show evidence: every fact needs a quote, and Python rejects quotes that aren't in the text or aren't about the rules.
  • Tested each prompt against hand labels; a sharper prompt plus a wording check lifted the "easy rules" field from 50% to 96% correct.
  • Cut model calls so cost and time fell about 70% without changing any answer.

Possible improvements

  • Make the evidence checks understand meaning instead of matching words: "a simple character-building system" still counts as simple rules.
  • Rank the games that pass, using the request's wishes, instead of returning the first one.
  • Improve the weakest field, features to avoid like timers or player elimination (94% correct).

How trust in the media forms and spreads A four-group differential-equation model of trust and distrust, built for my ODE course.

The model splits a population into neutral, exposed, trusting and distrusting groups. Try it: switch country scenario or drag the sliders.

dSdt=−(β + α)S + δT + μD − ψDS
dEdt=βS + ψDS − σE
dTdt=(1 − θ)σE + αS − δT
dDdt=θσE − μD
β
exposure rate
σ
processing rate
α
institutional reinforcement
δ
trust decay
μ
distrust recovery
ψ
echo chambers

What I did

  • Wrote an RK4 solver from scratch and compared a polarized UK scenario with a high-trust Finland scenario, starting from OECD-based shares.
  • Found the equilibria and their stability with phase-plane and eigenvalue analysis (without echo chambers, ψ = 0).
  • Showed that distrust outlasts its causes: when conditions improve, it fades more slowly than trust recovers (μ < δ).

Possible improvements

  • Fit the rates to real survey data over time instead of setting them by hand, and report how uncertain they are.
  • Run a global sensitivity analysis to find which rates drive long-run trust the most.
  • Extend the stability analysis to the full model with echo chambers (ψ > 0).

Source checker Paste a news link to see its source's credibility and political leaning.

A web app that checks where an article comes from. I'm growing it into an AI-assisted investigation tool that connects information across sources.

Working today

  • A FastAPI backend that downloads and parses the article with Newspaper3k.
  • Scores the source against a table of credibility ratings and political bias.
  • A React frontend showing the score, the bias and a 500-character preview.

In development

  • NLP classification of claims and content.
  • Entity linking, so the same person or company is recognized across sources.
  • Graph analysis to connect information and support evidence-driven investigation.

Possible improvements

  • Replace the small built-in ratings table with a maintained, documented ratings dataset.
  • Show why a source got its score, so people can judge the rating themselves.
  • Evaluate the classifier and entity linking on labelled data before relying on them.
  • Deploy it online so anyone can try it.
